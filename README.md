# The Robot Vacuum's Best Excuse

The funniest one-line excuse a robot vacuum gives for missing a spot — in the vacuum's own voice, blamed squarely on its map.

> "I didn't miss that spot — my map says it doesn't exist. I cleaned the floor plan, not the floor."

Entry for the [make.fun bounty](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214).

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Deterministic: the program writes one fixed line, no randomness, no clock, no network.
